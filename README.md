# Ativos visuais do PAINEL MILAE COINT

Repositorio publico e isolado destinado exclusivamente aos icones institucionais usados na instalacao do **PAINEL MILAE COINT** em desktop, Android e iOS.

Este repositorio nao contem codigo-fonte, dados operacionais, credenciais, configuracoes, relatorios ou integracoes do sistema.

A pagina inicial tambem funciona como instalador seguro para o iOS. O atalho usa a identidade visual hospedada neste dominio e encaminha o usuario ao link oficial do Apps Script, onde a autenticacao e as permissoes permanecem obrigatorias.

## Arquivos publicos

- `icon-192.png`: icone padrao de 192 x 192 px.
- `icon-512.png`: icone padrao de 512 x 512 px.
- `apple-touch-icon.png`: icone de 180 x 180 px para atalhos do iOS.
- `manifest.webmanifest`: identidade instalavel do aplicativo.

# Ativos visuais do PAINEL MILAE COINT

Repositório público e isolado destinado exclusivamente aos ícones institucionais usados na instalação do **PAINEL MILAE COINT** em desktop, Android e iOS.

Este repositório não contém código-fonte, dados operacionais, credenciais, configurações, relatórios ou integrações do sistema.

A página inicial também funciona como instalador seguro para o iOS. O atalho usa a identidade visual hospedada neste domínio e encaminha o usuário ao link oficial do Apps Script, onde a autenticação e as permissões permanecem obrigatórias.

## Arquivos públicos

- `icon-192.png`: ícone padrão de 192 x 192 px.
- `icon-512.png`: ícone padrão de 512 x 512 px.
- `apple-touch-icon.png`: ícone de 180 x 180 px para atalhos do iOS.
- `manifest.webmanifest`: identidade instalável do aplicativo.
- `territorios-portaria-262-2025.geojson`: limites municipais simplificados da
  Bahia, derivados da Malha Municipal Digital 2025 do IBGE e classificados
  conforme a Portaria SSP nº 262/2025. O arquivo contém apenas limites e
  referências administrativas públicas; não contém ocorrências ou dados de
  usuários do MILAE.
